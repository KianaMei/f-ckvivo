# fuckmyphone

vivo X Fold6（PD2545D / OriginOS 7）个人底层研究、原创模块与上游二改工作仓。`originos/` 收录设备侧研究（root / 内存 / 侧边栏），`original-modules/` 收录无上游代码基线的原创模块，`upstream-derived/` 收录基于上游项目修改的补丁、合包与整树维护源码。

所有目录导航、`forks/`（各自独立 Git，`.gitignore` 屏蔽）与 `cache/`（本地大件缓存，`.gitignore` 屏蔽）说明、上游仓库找回清单、工具链规范及**最高优先级设备红线**统一维护在 **[`AGENTS.md`](AGENTS.md)**（避免双份文档漂移），动手前请直接阅读。
