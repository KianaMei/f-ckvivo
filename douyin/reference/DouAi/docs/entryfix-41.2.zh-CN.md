**41.2 分享入口修复：0.2.72 / 173（modern）**

172 的分享入口存在实际遗漏：只识别旧的 `SharePanelDialog` 和 `CommonShareDialog`，会跳过原包中的 `CommonShareDialogPanel` 与 `SocialActionsPanel`；还会在 SharePackage 尚未就绪时直接跳过显示。新增回归使用原包的新窗口类名和数据字段，在窗口回调处复现了“没有按钮”，修复前已确认失败。

长按作品页的评论图标打开融合总菜单。入口实际安装在 41.2 启动分支，通过 Activity 的触摸派发识别当前作品卡片中的评论操作。长按期间不向宿主转交这段触摸，避免同时触发倍速；短按重新交给原生评论按钮，移动则取消菜单识别并恢复原生滑动。原来加在旧 `FeedGestureToolsHook` 中而无法在 41.2 执行的代码已移除。

分享页新增“↓ 模块下载”，不要求原面板提供下载 action。173 补齐 `CommonShareDialogPanel`、`SocialActionsPanel`、`DialogPanel`、底部和横屏分享基类及其派生窗口，保留此前两种窗口。基础窗口 show/onStart 与各面板自身 onCreate/show 共同触发插入，各旧类独立安装，缺少其中一类不会撤销其他入口。

按钮先显示，点击时再读取该窗口最新绑定的分享数据。普通分享按分享包的作品标识找对应作品；社交/日常面板可以直接使用其配置中明确持有的 Aweme，不需要虚构全局“当前作品”。新增入口调用模块内置下载器，不依赖第三方解析服务。数据尚未就绪时保留分享页并说明原因，不取其他作品的数据代替。下载开关关闭时保留入口，点击提示开启。

插入优先选择底部分享容器，无法按资源名找到时使用窗口 decor，移除 content 必须是 FrameLayout 的限制。按钮设置独立层级，布局观察会补回被宿主重建移除的按钮；重复窗口回调不会重复添加，关闭窗口和卸载入口会移除按钮与观察器。

宿主“复制诊断”现在附带最近窗口类、命中的分享窗口、插入/恢复/点击计数、数据就绪状态、可见性与最近异常。模块状态快照也包含这些字段；未安装时显示安装失败原因，不能再把 installed=true 当作实际显示成功。诊断不含媒体 URL 或账号凭据。

播放来源按 `VideoRef.mVideoId` 与作品的播放资源标识或 `video_model.video_id` 关联，缓存有数量与时间上限。预加载另一作品不会覆盖当前作品；空结果清除其自己的旧缓存。选择器使用同一作品的来源快照，直接保存和来源选择共用此快照。独立音轨、已识别的分离音视频、播放列表和加密流不被冒充为完整 MP4；这些形式需要额外的解封装或合并能力，本次没有据此宣称任意可播放内容都能保存。

播放来源捕获与普通下载独立安装：捕获接口不可用时，已有模型地址下载仍可工作。“关于”主入口和侧栏项已移除，“调试与日志”保留在“扩展功能”。

本次只验证 10 个相关用例：4 个窗口插入/延迟绑定/日常作品/布局恢复与关闭场景、4 个原始 41.2 APK 合约、2 个既有真实 HTTP 到文件夹保存场景。最初失败的可见性断言同时修正了测试窗口尺寸，让其通过 Android 窗口重新布局后再检查可见区域。另检查 modern APK 的版本、原签名和实际 DEX 安装引用。电脑没有连接手机，因此这些结果不等于真机分享面板已确认显示。日志和分析留在工作目录，交付目录只放一个 APK。

交付文件：`dist/download-fixed-41.2/Douyin-Unified-41.2-modern.apk`。包名和签名延续原版本，可覆盖安装；安装后需彻底结束抖音进程再启动，以重新加载模块代码。
