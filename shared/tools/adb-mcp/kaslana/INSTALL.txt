# kaslana 部署说明（Antigravity App / IDE / CLI 直连）

机械革命走 Cloudflare 命名隧道，公网地址固定：`https://adb-mcp.mamba-out.com/mcp`。
kaslana 只需配置一次，没有定时任务、没有 DNS 发现。

## 一次性安装

在仓库根目录打开普通 PowerShell（无需管理员）：
```powershell
powershell -ExecutionPolicy Bypass -File .\shared\tools\adb-mcp\kaslana\Resolve-AdbMcp.ps1
```
脚本会：
- 从同仓 `shared/tools/adb-mcp/secrets/token.txt` 读 Bearer token（或 `-Token <...>` 传入）
- 合并写入 `%USERPROFILE%\.gemini\config\mcp_config.json` 的 `adb-phone` 条目（保留其它 MCP 条目）
- 删除旧版遗留的 `adb-mcp-resolve` 计划任务（quick tunnel 时代每 5 分钟同步 URL 用，会闪黑窗）

不克隆仓库也行：手动在 `mcp_config.json` 加
```json
"adb-phone": {
  "serverUrl": "https://adb-mcp.mamba-out.com/mcp",
  "headers": { "Authorization": "Bearer <secrets/token.txt 内容>" },
  "timeoutSeconds": 30
}
```

## 生效与重连（三端共用 `~/.gemini/config/mcp_config.json`）

- **Antigravity App (2.0)**：左侧栏 **Customizations → Installed → MCP Servers**，`adb-phone` 点 **⋮ → Restart**。
- **Antigravity IDE**：Agent 侧栏右上角 **… → MCP Servers → Manage MCP Servers** 刷新。
- **Antigravity CLI (`agy`) / paseo**：`/mcp` 重载，或在 paseo 对 agent 点 **Reload agent**。

验证：让 agent 调用 `adb_devices`，预期返回 `10AG632QLS002CF  device  model:V2545A`。

## 日常注意

- 地址固定，机械革命重启/重连后自动恢复，kaslana 无需任何动作。
- token 泄露 = 别人能只读查手机（不能写文件、不能装包、不能重启——红线在机械革命服务端强制拦截）。怀疑泄露时在机械革命重生成 `secrets/token.txt`、重启 daemon 并 `git push`，kaslana `git pull` 后重跑一次本脚本。
- kaslana 不需要装 `adb` / `cloudflared`，不需要插手机。
